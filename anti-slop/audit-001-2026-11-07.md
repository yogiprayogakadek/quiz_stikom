## Daftar Temuan (Numbered Findings List)

1. **[R-26] Input pencarian di Dashboard Top Bar belum memiliki handler submit/filter aktif**  
   *Tingkat Prioritas: HIGH (Hard Gate)*  
   Elemen input pencarian di `peserta/dashboard.blade.php` dan `admin/dashboard.blade.php` saat ini hanya berupa elemen input visual tanpa handler event JavaScript / form action.

2. **[R-25] Tingkat kontras warna teks pendukung (`text-slate-400`) pada latar belakang putih**  
   *Tingkat Prioritas: HIGH (Hard Gate)*  
   Teks pendukung kecil seperti subtitle label dan placeholder masih menggunakan `text-slate-400` yang berada di ambang batas rasio WCAG AA (disarankan ditingkatkan ke `text-slate-500`).

3. **[R-06] Penggunaan label uppercase dengan tracking lebar pada tag pill/subtitle**  
   *Tingkat Prioritas: LOW (Quality Locks)*  
   Sub-label seperti `Learn · Practice · Win` dan status pill menggunakan `uppercase tracking-wider` yang dapat disederhanakan ke bentuk sentence case.
